# Universal-MCU-Platform
One PCB that sockets 6 different MCU dev boards (ESP32, ESP32-S3, ESP8266, Nano, RP2040, STM32) for any mechatronics project.
This PCB fabrication run was sponsored by **[NextPCB](https://www.nextpcb.com/?code=Abdullah)**.
